# Авито: обучение с исходных данных

[Открыть в Google Colab](https://colab.research.google.com/github/revefffect/avito-contest/blob/main/colab/solution.ipynb)

Откройте `solution.ipynb` в Google Colab, выберите среду с GPU и выполняйте ячейки сверху вниз. Ноутбук загрузит исходные данные, построит индексы и признаки, обучит две модели CatBoost и создаст новый `answer.csv`. Готовые модели конкурса, признаки и ответы не скачиваются.

Для запуска достаточно одного ноутбука. Весь код решения виден в его ячейках. Ячейки `%%writefile` сохраняют этот текст в локальные файлы рабочей папки, затем этапы выполняются отдельными процессами. Скрипты решения из GitHub не скачиваются. Такой способ позволяет освобождать память между этапами. Данные, модели и результаты создаются в отдельной рабочей папке, указанной в первой ячейке.

Сам перенос кода в ноутбук почти не меняет время расчёта или объём RAM. Размер файла ноутбука составляет около 195 КБ, основные ресурсы по-прежнему нужны для E5, индексов и обучения CatBoost.

## Что обучается

Словный и символьный TF-IDF, BM25, статистики запросов и географии рассчитываются из исходных таблиц. Два CatBoostClassifier обучаются заново на 4500 локальных запросах. Ещё 1500 запросов оставлены для audit, они не используются при обучении. Глубина деревьев равна 6, число деревьев 700 и 1000, веса моделей 0,5 и 0,5. Параметры зафиксированы по предыдущим экспериментам, новый audit не выбирает модель.

E5 служит общим языковым представлением. Его открытые предобученные веса скачиваются из Hugging Face с фиксированной ревизией. Обучения E5 с произвольных начальных весов здесь нет. Все эмбеддинги объявлений и запросов рассчитываются заново [1].

## Ресурсы и результат

Нужен Python 3.12 и интернет для установки библиотек, загрузки данных и E5. Код поддерживает NVIDIA GPU через CUDA. В справке Colab указан runtime 2026.07 с Python 3.12.13, его можно выбрать в настройках среды, если версия по умолчанию изменилась [2]. PyTorch 2.9.1 устанавливается из официального репозитория колёс CUDA 12.6 [3].

Для полного расчёта ориентируйтесь на 16 ГБ оперативной памяти и 20 ГБ свободного диска. Такие значения являются запасом для планирования, не измерением потребления Colab. Один сохранённый лексический индекс исходного решения занимает около 1,8 ГБ. GPU ускоряет E5, индексы, признаки и CatBoost выполняются на CPU. Время полного запуска в Colab пока не измерено. Доступные ресурсы и длительность сессии Colab не гарантированы [4].

На выходе:

- `answer.csv` с 2452 запросами и 50 объявлениями на запрос
- `reports/audit.json` с качеством заново обученных моделей
- `reports/reproducibility.json` с версиями, параметрами, SHA256 кода и ответа
- `reports/run_steps.json` и журналы этапов

Прежний CSV был получен на Apple MPS. Переход на CUDA, другой размер пакета и явная реализация attention могут изменить числа и итоговый порядок объявлений. Совпадение со старым CSV показывается отдельно и не выдаётся за гарантированное. Для проверки нового результата используйте CSV и отчёты, созданные одним запуском этого ноутбука. Семена и основные версии библиотек закреплены. Полная межплатформенная побайтовая воспроизводимость не заявляется.

## Локальный запуск

Для Python 3.12 в новом окружении установите PyTorch 2.9.1 для своего устройства и зависимости из `requirements.txt`. Затем:

```bash
python scripts/from_scratch.py --stage all --device auto
```

Аргумент `--dataset-archive /path/to/dataset.zip` позволяет использовать собственную копию исходного архива. Его контрольная сумма проверяется. Любой этап можно выполнить отдельно через `--stage`, список показывает `--help`. Повторное обучение создаёт новые CatBoost-модели, не продолжает обучение старых.

Локальная проверка этого варианта описана в `verification.json`. Проверка на небольшой выборке не является оценкой качества полного решения и не заменяет запуск в Colab.
