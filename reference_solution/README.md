# Поиск объявлений услуг Авито

Готовое решение конкурса: для каждого из 2 452 запросов выбираются 50 объявлений
из корпуса в 189 212 записей. Основной файл для первой попытки — `answer.csv`.
Репозиторий содержит код подготовки данных, поиска, обучения, проверки и сборки
ответа; параметры выбранного решения зафиксированы в `configs/final.json`.

Поиск объединяет BM25, словный и символьный TF-IDF, локальную модель
multilingual-e5-small, географию и статистики обучающих взаимодействий.
Две модели CatBoost отбирают итоговые объявления из объединённого списка.
Одна использует прямую историю выбора объявлений, другая исключает её признаки;
оценки моделей стандартизуются внутри запроса и усредняются с равными весами.

## Результаты

На dev (1 500 запросов), до финального переобучения:

| Вариант | Recall@50 | С поправкой на долю пустых фильтров |
|---|---:|---:|
| Лексический поиск с географией | 85.88% | 85.66% |
| Лексические кандидаты + CatBoost | 92.99% | 92.38% |
| Гибридный поиск без обученного отбора | 87.81% | 86.95% |
| Гибрид + CatBoost с историей | 94.26% | 93.64% |
| Гибрид + CatBoost без прямой истории | 93.92% | 93.51% |
| Выбранная равная смесь | 94.29% | 93.71% |

Ансамбль улучшил dev на 0,033 процентного пункта относительно одиночной модели.
95% парный bootstrap-интервал разницы: от −0,43 до +0,50 п.п. Статистически
надёжное превосходство здесь не установлено. Выбор и варианты зафиксированы
до просмотра audit; после него настройки не меняются.

Независимый audit (1 500 запросов), после обучения на fit + dev:

| Финальный вариант | Recall@50 | С поправкой на долю пустых фильтров |
|---|---:|---:|
| Основной ансамбль | 94.11% | 94.32% |
| С прямыми признаками истории | 93.98% | 94.16% |
| Без прямых признаков истории | 94.64% | 94.87% |

95% bootstrap-интервал Recall@50 основного ответа: 92.91%–95.24%.
Полнота общего набора кандидатов до отбора 50 — 98.87%.
Вариант без прямой истории на audit оказался выше, хотя на dev был ниже.
Основной выбор сохраняется по заранее зафиксированной процедуре. Значение
на скрытом benchmark неизвестно. [Полный отчёт audit](reports/final_audit.json).

Разделение фиксировано: 3 000 запросов для обучения отбора, 1 500 для выбора
настроек и 1 500 для независимой проверки. После выбора настроек финальные
модели переобучаются на первых 4 500 запросах. Отложенные взаимодействия удалены
до расчёта поведенческих признаков. Поиск проверяется на полном корпусе,
дополненном целевыми объявлениями из обучающих данных.

Локальная проверка намеренно сложная по новизне объявлений: 96,56% целевых
объявлений не имеют обучающей истории. Доля таких объявлений среди скрытых
ответов неизвестна. Локальный Recall нельзя считать обещанием балла на платформе.
Дополнительная метрика учитывает известную долю запросов без фильтров в benchmark.

Подробности: [метод и ограничения](docs/method.md),
[зафиксированный выбор до audit](configs/selection.json),
[разбор ошибок исходного поиска](reports/lexical_error_analysis.md).

## Какой файл отправлять

1. Начать с `answer.csv`: равная смесь двух моделей, выбранная по dev.
2. `answer_with_history.csv` и `answer_no_history.csv` — отдельные компоненты
   смеси для дальнейшего сравнения. Не стоит тратить обе попытки автоматически:
   сначала полезно увидеть результат основного ответа.
3. Сохранить полученный балл и имя отправленного файла. Для проверки решения
   предоставить код вместе с соответствующей конфигурацией и артефактами.

Название `no_history` относится только к прямым счётчикам выбора конкретных
объявлений. Статистики похожих запросов, подкатегорий и географии, а также общий
набор кандидатов остаются в обоих вариантах.

Попытки на платформе не использовались. Публикация кода и загрузка ответа
выполняются отдельно; локальный ZIP сам по себе не является публичной ссылкой.

## Быстрое повторение ответа без сети

Архив `deliverables/avito_solution.zip` содержит исходники, готовые модели,
числовые признаки benchmark, таблицы идентификаторов и ответы. Распаковать его
в отдельную папку, установить зависимости и выполнить:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e .
python scripts/reproduce.py --output answer_reproduced.csv
```

После установки зависимостей команда не обращается в сеть. Она проверяет хеши
входных файлов, заново применяет модели, собирает топ-50 и сравнивает SHA256
с выпущенным `answer.csv`. Готовый CSV не используется как источник предсказаний.
Исходные тексты, обучающие пары, веса E5 и большие промежуточные индексы в этот
компактный архив не входят. Для повторения другого варианта:

```bash
python scripts/reproduce.py --config configs/with_history.json --output answer_with_history_reproduced.csv
python scripts/reproduce.py --config configs/no_history.json --output answer_no_history_reproduced.csv
```

Повторный запуск основного ответа дал побайтно одинаковый CSV. Его SHA256:
`3ebda47a966aa2920fe9480cb3b4b1602ec91b63f207d89775d981d16995e3c6`.
Проверка архива выполняется отдельно после распаковки; её отчёт сохраняется
рядом с архивом в `deliverables/verification.json`.

## Полная сборка из исходных данных

Использовался Python 3.12.7; версии основных библиотек закреплены в
`pyproject.toml`. Для эмбеддингов доступны CPU и Apple MPS. Подготовка данных,
весов и зависимостей требует интернета; вычисления после подготовки работают
локально и не используют внешние API.

```bash
pip install -e ".[dense,dev]"
python scripts/download_data.py
python scripts/prepare_dense.py --download-model --download-only
python scripts/reproduce.py --rebuild --device auto --output answer_rebuilt.csv
```

Готовый архив данных можно передать через
`python scripts/download_data.py --archive /path/to/dataset.zip`.
Веса E5 закреплены по ревизии `614241f622f53c4eeff9890bdc4f31cfecc418b3`.
Полная сборка повторяет разделение, индексацию, эмбеддинги, обучение двух моделей
и поиск benchmark. Проверка качества audit не входит в подбор настроек.

Эмбеддинги текущего решения получены на Apple MPS в float32. Полная сборка
на другом устройстве может дать небольшие численные отличия; побитовое
совпадение полного переобучения между CPU и MPS не проверялось. Скрипт сообщает
о несовпадении итогового хеша, а не скрывает его. Для точного повторения
выпущенного ответа предназначен быстрый запуск из сохранённых признаков и моделей.

## Проверка файлов и кода

```bash
python -m avito_retrieval.submission --answer answer.csv --queries data/ids/benchmark_queries.parquet --items data/ids/benchmark_items.parquet
python -m pytest -q
```

Проверяются две колонки CSV, все исходные запросы, регистр и длина ID,
принадлежность объявлений корпусу, отсутствие повторов и ограничение 50.
Идентификаторы сохраняются строками, включая ведущие нули.
В использованном Anaconda-окружении тесты запускались без сторонних плагинов
и перехвата вывода:

```bash
PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 python -m pytest -p no:capture -q
```

Пройдены 67 тестов; проверка форматирования и компиляции кода также успешна.

Для повторной упаковки уже подготовленного решения:

```bash
python scripts/package_solution.py --output deliverables/avito_solution.zip
```

Архив содержит `manifest.json` с размерами и SHA256 файлов. Ответы не зашиты
в код; `query_id` служит для сопоставления строк и сохранения CSV, а модель
не получает ни идентификатор запроса, ни позицию объявления в корпусе.
