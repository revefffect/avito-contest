# Повторение проверок

Для получения `answer.csv` достаточно пяти ячеек в `mini/solution.ipynb`. Скрипты в этой папке нужны для дополнительной проверки, сборки материалов и повторения аудита.

## Ноутбук в отдельной папке

После установки `mini/requirements.txt` выполните из корня репозитория:

```bash
python scripts/verify_notebook.py --mini-root mini
```

Проверяющий скрипт копирует входные файлы во временную папку, удаляет сохранённые результаты ячеек и запускает новый Jupyter kernel. Готовый CSV не копируется. Отчёт записывается в `deliverables/notebook_verification.rerun.json`, исходный ноутбук остаётся прежним. Для работы нужны `nbclient`, `nbformat` и `ipykernel`, которые входят в установленное окружение Jupyter. Jupyter использует локальные соединения, внешние сервисы для расчёта не нужны.

## Полный независимый аудит

```bash
python scripts/independent_audit.py --solution-root "/path/to/full/avito contest"
```

Для этой проверки нужна полная рабочая папка исходного решения с сырыми данными, результатами подготовки, признаками локальной проверки и обученными моделями. Компактные архивы релиза содержат признаки benchmark для получения ответа, поэтому одних этих архивов для полного аудита недостаточно. Подготовка данных описана в [полном решении](../reference_solution/README.md).

Скрипт пересчитывает 87 проверок и сохраняет новые отчёты в `deliverables/independent_audit_rerun/`. Он не обучает модели, не выбирает параметры и не меняет сохранённые отчёты. В расчёт входят разделение данных, полная разметка в знаменателе Recall@50, пропуски генерации кандидатов и срез без общих целевых объявлений.

## Проверка мини-архива

```bash
python scripts/package_mini.py verify --archive deliverables/avito_mini.zip
```

Проверяются все имена, размеры и SHA256 файлов по двум манифестам внутри ZIP. Команда `build` собирает новый архив из текущего дерева проекта. При изменении исходных файлов его контрольная сумма также изменится. Опубликованный архив сохраняет состав на момент сборки, дополнительные проверяющие скрипты доступны в репозитории.

`package_evidence.py --help` описывает отдельную сборку индекса и архива доказательств. Для обновления индекса скрипту нужна исходная папка решения. `build_notebook.py` и `execute_notebook.py` использовались при подготовке ноутбука, их запуск не требуется для воспроизведения готового ответа.
