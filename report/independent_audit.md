# Независимая проверка сохранённого решения

Проверка выполнена без обучения, подбора весов и изменения исходного решения. Исходная папка `avito contest` использовалась только для чтения. Итог: 87 из 87 проверок пройдены.

## Данные и разделение

В исходных файлах 497 673 обучающих строк, 2 452 запроса benchmark и 189 212 объявлений. Идентификаторы benchmark уникальны, имеют ожидаемый строковый формат и сохраняют исходный регистр. Расширенный корпус содержит 195 125 объявлений, из них 5 913 добавлены для локальной проверки.

В `retrieval_train` отсутствуют все 6 432 скрытые пары «контекст запроса, объявление» и все 3 756 выбранные новые тексты. Пересечения равны нулю. Идентификаторы, контексты и нормализованные тексты запросов fit, dev и audit попарно не пересекаются. Размеры частей составляют 3000, 1500 и 1500 запросов. Между fit и dev встречаются 19 общих целевых item_id, между fit и audit 12, между dev и audit 10. В объединении fit+dev и audit общих целевых item_id 22. Разделение является запросным, но не полностью раздельным по объявлениям.

## Прямой пересчёт качества

Сохранённые CatBoost-модели заново рассчитали оценки только для audit. Реализация метрики из проекта не импортировалась. Для каждого запроса объявления упорядочены по оценке с разрешением ничьих по позиции в корпусе. Числитель равен пересечению первых 50 кандидатов со всей доступной разметкой, знаменатель равен числу всех известных положительных объявлений этого запроса. Затем взято обычное среднее по 1500 запросам.

Для зафиксированного ансамбля Recall@50 равен **0.941111111111**. После взвешивания групп по доле пустых фильтров в benchmark он равен **0.943177811263**. Доля пустых фильтров независимо пересчитана как 0.630505709625. Все сохранённые значения по запросам и итоговые метрики трёх фиксированных вариантов совпали с пересчётом с допуском 1e-12.

Полнота исходного гибридного пула равна 0.988666666667. В нём не хватает 18 положительных объявлений у 18 запросов, из которых 16 не имеют ни одного найденного положительного объявления. Пропущенные положительные объявления остались в знаменателе. Ошибочная замена знаменателя на найденные положительные с удалением нулевых запросов дала бы 0.951931716083 и завысила бы оценку.

Для описательной сверки также измерена полнота ранее сохранённого лексического пула на тех же audit-запросах: 0.969333333333. Значение не использовалось для выбора модели.

## Чувствительность к общим целевым объявлениям

После фиксации модели дополнительно исключены все audit-запросы, у которых хотя бы один целевой item_id встречается среди целевых item_id fit или dev. Удалены 22 запроса и 46 положительных пар. Осталось 1478 запросов и 1573 положительные пары. Пересечение известных целевых item_id с fit+dev стало нулевым.

Recall@50 основного зафиксированного ансамбля на оставшейся части равен **0.941249436175**, показатель с прежней долей пустых фильтров benchmark равен **0.942929047334**. Маска исключения рассчитана непосредственно по truth. Значения по запросам взяты из таблицы, для которой выше подтверждено полное совпадение с независимым пересчётом.

Дополнительный срез не использовался для изменения модели или весов. Исключение относится к известным целевым объявлениям. Сам корпус кандидатов остаётся общим, поэтому полностью раздельного по объявлениям эксперимента здесь нет.

## Файлы ответа

Три текущих CSV имеют по 2452 уникальных запросов и по 50 разрешённых объявлений в строке. Хеши совпадают одновременно с конфигурациями и с прежним отчётом фактического воспроизведения из ZIP. Сам ZIP также совпал с ранее проверенным архивом. Архив в этой проверке заново не распаковывался.

## Неизвестности и границы

- Скрытая метрика платформы не наблюдалась. Локальный audit не равен результату benchmark.
- Положительные пары отражают наблюдённый выбор. Полная релевантность остальных объявлений неизвестна.
- Перенос с учётом доли пустых фильтров корректирует только один наблюдаемый сдвиг состава запросов.
- Разделение выполнено по запросам. Между fit+dev и audit есть 22 общих целевых item_id.
- Проверен один сохранённый split. Независимое повторное обучение и вариативность между split здесь не измерялись.
- Исторический порядок выбора модели подтверждается сохранёнными конфигурациями и отчётами, а не независимым журналом событий.
- Повторное получение трёх CSV в этой проверке не запускалось. Проверены текущие хеши и прежний успешный отчёт фактического воспроизведения.

## Источники и метод

Полные значения, результаты каждой проверки и контрольные суммы сохранены в [independent_audit.json](independent_audit.json).

- [E002](../evidence/INDEX.md#E002) описывает исходный архив конкурса и контрольные суммы трёх Parquet-файлов. Сырые файлы доступны по исходной ссылке конкурса, в комплект доказательств они повторно не включаются.
- [E006](../evidence/INDEX.md#E006) фиксирует разбиение, [E007](../evidence/INDEX.md#E007) подтверждает его повторную сборку.
- [E015](../evidence/INDEX.md#E015) содержит результаты по запросам, [E021](../evidence/INDEX.md#E021) фиксирует конфигурацию.
- [E020](../evidence/INDEX.md#E020) подтверждает прежнее воспроизведение трёх ответов из архива.
- [E032](../evidence/INDEX.md#E032) содержит эту независимую проверку, [E033](../evidence/INDEX.md#E033) содержит проверку мини-ноутбука.
