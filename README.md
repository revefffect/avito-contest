# Avito: воспроизводимое решение в Jupyter

Отдельный комплект для проверки конкурсного решения. Основной рабочий проект сохранён без изменений.

Начните с [мини-ноутбука](mini/solution.ipynb). Пять исполняемых ячеек проверяют входные файлы, применяют две модели CatBoost, выбирают 50 объявлений и записывают `answer.csv`. Готовый ответ не читается. В независимом запуске без заранее созданного CSV получен исходный SHA256.

## Запуск

Скачайте `avito_mini.zip` из [релизов проекта](https://github.com/revefffect/avito-contest/releases) и распакуйте его. Числовые признаки занимают 257 МБ и находятся в архиве релиза. Используйте Python 3.12. Проверенный запуск выполнен на Python 3.12.7. После установки зависимостей вычисления не обращаются к сети.

```bash
cd mini
python -m pip install -r requirements.txt
jupyter lab solution.ipynb
```

В Jupyter выберите Restart Kernel and Run All Cells. На выходе появится `mini/answer.csv` с 2 452 запросами по 50 объявлений. Ожидаемый SHA256:

`3ebda47a966aa2920fe9480cb3b4b1602ec91b63f207d89775d981d16995e3c6`

Мини-ноутбук повторяет применение готовых моделей к сохранённым признакам. Полная подготовка текстовых индексов, E5 и обучение описаны в исходном решении. Такой расчёт требует исходных данных и весов, которые перечислены в индексе доказательств. Архив `avito_solution.zip` в том же релизе содержит исходный переносимый комплект с кодом, признаками и моделями для воспроизведения всех трёх вариантов CSV. Отдельный `avito_evidence.zip` содержит индексированные материалы проверки.

## Результат и границы

Основной ансамбль получил Recall@50 94,1111% на 1 500 локальных audit-запросах. После исключения запросов с целевыми объявлениями, общими с обучением отбора, показатель равен 94,1249% на 1 478 запросах. Оба числа относятся к сохранённой локальной проверке. Скрытый балл платформы неизвестен.

Для проверки использованы 87 независимых проверок данных и метрик. Новый ноутбук отдельно выполнен в чистой папке, а исходный переносимый архив ранее воспроизвёл все три варианта CSV. [Протокол ноутбука](report/notebook_verification.json).

Правила редактуры прочитаны по двум указанным репозиториям без клонирования и установки их кода. [Применённые правила](report/editorial_rules.md).
